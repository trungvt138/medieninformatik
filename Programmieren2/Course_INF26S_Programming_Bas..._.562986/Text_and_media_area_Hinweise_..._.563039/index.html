Hinweise zu Maven auf den Pool-Rechnern

Auf den Rechnern in Raum E46 ist eine IntelliJ-Version von 2022 installiert. Beim Initialisieren des Projekts mit Maven stürzt es zwar nicht ab, aber es wird beispielsweise kein Inhalt der pom.xml erzeugt. 

Vermutlich treten noch mehr Probleme auf. Daher:

Wenn ihr die Pool-Rechner verwendet, verwendet gerne die von IntelliJ vorinstallierte Version von Java (z.B. Oracle 19).
