# Reguläre Ausdrücke

In diesen Notebooks lernst du, Textmuster zu formulieren und mit Python anzuwenden. Die Beispiele sind frei erfunden und benötigen keine zusätzlichen Datendateien.

| Notebook | Inhalt |
| --- | --- |
| [01_regex_syntax.ipynb](01_regex_syntax.ipynb) | Übe Regex-Syntax mit kurzen Aufgaben und vorbereiteten Testzellen. |
| [02_regex_api.ipynb](02_regex_api.ipynb) | Nutze Python-Funktionen für Suche, Prüfung und Extraktion; prüfe Datumsfelder. |

## Start im JupyterHub

1. Öffne den [JupyterHub der Hochschule](https://jupyterhub.informatik.haw-hamburg.de), melde dich mit deiner HAW-Kennung an und wähle eine CPU-Umgebung. Hinweise zum Zugang stehen in der [HAW-Anleitung](https://doc.inf.haw-hamburg.de/Dienste/jupyterhub/).
2. Öffne im Dateibrowser das erste Notebook, wähle bei Bedarf den Kernel **Python 3** und führe die Zellen der Reihe nach aus. Öffne für den zweiten Teil das zweite Notebook und führe auch dort die Importzelle aus.
3. Ergänze die vorgesehenen Stellen und führe die anschließenden Testzellen aus. Die Tests bestehen, sobald deine Lösung die jeweiligen Fälle korrekt behandelt.

Falls du ein eigenes Repository oder ein ZIP-Archiv erhältst, lade beziehungsweise klone es zunächst in deine Arbeitsumgebung. Beide Notebooks verwenden nur `re` aus der Python-Standardbibliothek und benötigen keine zusätzlichen Fachpakete.

## Auf dem eigenen Rechner arbeiten

Klone das Repository lokal oder lade es als ZIP-Datei herunter und entpacke es. Die [Startanleitung für Python mit `venv` und Docker Compose](local/README.md) enthält die Befehle für die lokale Umgebung.
