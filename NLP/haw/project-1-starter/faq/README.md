3. [Wie analysiere ich die dokumentierten Auffälligkeiten?](notebooks/03_analyze_findings.ipynb) – Häufigkeiten, Textunterschiede und CSV-Import in Excel
4. [Wie schreibe ich meine Meldungen als CSV-Datei?](notebooks/04_write_predictions.ipynb)
5. [Welche Kennzahlen erreicht mein Verfahren?](notebooks/05_evaluate.ipynb)
6. [Wie verwende ich Code aus einer eigenen Python-Datei im Notebook?](notebooks/06_import_python.ipynb)
