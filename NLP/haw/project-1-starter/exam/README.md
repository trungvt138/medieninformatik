# Prüfungsunterlagen für Projekt 1

- [Aufgabenstellung.pdf](Aufgabenstellung.pdf) enthält die Aufgabenstellung, den Link zu den Kursdaten und die Abgaberegeln.
- [GETTING_STARTED.md](GETTING_STARTED.md) ist die **optional Vorlage** für eure Anleitung zum Einrichten und Starten des Projekts.
- [RESULTS.md](RESULTS.md) ist eine **optionale Vorlage** für den kurzen Ergebnisbericht. Dokumentiert eure Validierungsergebnisse und Beispiele im Repository. Dafür könnt ihr auch ein Format wie etwa PDF verwenden.
- [BEITRAEGE_UND_KI.md](BEITRAEGE_UND_KI.md) ist eine **nicht-optionale Vorlage**. Jedes Teammitglied muss sie für den eigenen Beitrag und die eigene KI-Nutzung ausfülen.
