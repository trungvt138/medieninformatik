# IMDb-Trainingsreviews für die Notebooks 02–04

Die Ordner `train/pos` und `train/neg` enthalten jeweils 50 vollständige UTF-8-Textdateien aus dem Stanford Large Movie Review Dataset v1.0 (`aclImdb`). Dateinamen und Inhalte entsprechen dem Original. Im Namen `<id>_<rating>.txt` ist die letzte Zahl die IMDb-Bewertung von 1 bis 10. Die Klasse steht im Ordnernamen.

Quelle: Maas et al. (2011), [Learning Word Vectors for Sentiment Analysis](https://aclanthology.org/P11-1015/). Die Dateien stammen aus `aclImdb_v1.tar.gz` von der [Stanford-Datensatzseite](https://ai.stanford.edu/~amaas/data/sentiment/).
