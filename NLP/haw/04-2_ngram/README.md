# N-Gramme

| Notebook | Aufgabe |
| --- | --- |
| [01 · Bigramme selbst bilden](01_word_ngrams.ipynb) | Entwickelt gemeinsam eine Indexschleife und vergleicht die Wortpaare zweier Filmurteile. |
| [02 · kNN auf IMDb mit Wort-Bigrammen](02_knn_ngrams.ipynb) | Wiederhole den bekannten kNN-Lauf, ergänze Wortpaare im Vektorisierer und vergleiche die Trefferzahl. |
| [03 · Eine Filmreview mit N-Grammen erzeugen](03_ngram_language_model.ipynb) | Ziehe Folgewörter nach ihrer Häufigkeit und vergleiche drei Fortsetzungen für denselben Satzanfang. |
| [04 · Ein Sprachmodell bewerten](04_language_model_evaluation.ipynb) | Berechne eine geglättete Wahrscheinlichkeit und vergleiche drei Modelle anhand ihrer Perplexität auf 100 neuen Reviews. |

Jedes Notebook lässt sich einzeln öffnen. Führe seine Zellen von oben nach unten aus. Die Links am Anfang führen dich zur gemeinsamen Implementierung oder zur jeweiligen Übung.

Im JupyterHub genügt ein Python-Kernel. Für die Arbeit auf deinem Rechner gibt es eine [Anleitung für venv und Docker](local/README.md). Die [IMDb-Kursdaten](data/imdb/README.md) liegen als einzelne TXT-Dateien bei.
